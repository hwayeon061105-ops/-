## 1. 스프린트 목표
* PRD 섹션 6의 6가지 완료 조건을 전수 검증하고, 모바일/태블릿 반응형 뷰포트 및 웹 접근성(ARIA)을 최적화한다.
* 전체 사용자 여정(User Flow)에 대한 통합 테스트를 수행하고 최종 배포를 준비한다.

---

## 2. 작업 목록 (Tasks)

### Task 4.1: PRD 완료 조건 6개 항목 전수 테스트
- [ ] **TC-01 (응답 시간):** 키, 몸무게, 현재 마음가짐 입력 후 버튼 클릭 시 5~10초 사이에 결과가 표시되는가?
- [ ] **TC-02 (미입력 방어):** 입력 항목이 비어있을 경우 빨간 글씨로 `"00칸이 비어있어요"` 문구가 뜨고 다음 단계로 넘어가지 않는가?
- [ ] **TC-03 (로딩 애니메이션):** 처리 중(5~10초) 동안 조금씩 움직이며 운동하는 캐릭터 애니메이션이 렌더링되는가?
- [ ] **TC-04 (포맷 검증):** 결과 조언에 이모티콘/표정 특수문자가 포함되어 있으며, 정확히 3줄로 출력되는가?
- [ ] **TC-05 (에러 회복 탄력성):** AI 응답이 실패하더라도 화면이 멈추지 않고, '다시 하기' 또는 재시도 버튼이 정상 동작하는가?
- [ ] **TC-06 (새로고침 초기화):** 새로고침 시 초기 입력 페이지로 정상 되돌아가는가?

### Task 4.2: 크로스 디바이스 및 웹 접근성(A11y) 검증
- [ ] 모바일(iOS Safari, Android Chrome), 태블릿, 데스크톱 레이아웃 검증
- [ ] 스크린 리더 지원: `aria-live="polite"`, `role="radiogroup"`, `role="radio"`, `aria-checked` 상태 동기화
- [ ] 키보드 내비게이션(Tab, Enter) 및 포커스 링 시인성 확보

### Task 4.3: 프로덕션 빌드 및 최적화
- [ ] `pnpm build` 수행 및 TypeScript/Lint 에러 0건 확인
- [ ] 불필요한 번들 및 디버그용 버튼 정리
- [ ] 워크스루 문서(`walkthrough.md`) 업데이트 및 커밋/푸시
