# Sprint 2: AI 조언 생성 API & 프롬프트/포맷팅 파이프라인

> **스프린트 상태:** ✅ 완료 (Completed)  
> **진행 기간:** Sprint Day 3 ~ Day 5  
> **관련 PRD 섹션:** 4.2(AI 조언 요청 및 프롬프트 제어), 5.2(AI API Failure Exception), 5.3(Formatting Mismatch Exception)

---

## 1. 스프린트 목표
* Next.js 서버 사이드 Route Handler(`/api/advice`)를 구축하여 사용자의 신체 정보, 심정, 선택 톤을 바탕으로 AI 조언을 생성한다.
* 프롬프트 엔지니어링을 통해 이모티콘/특수문자 포함 및 3가지 톤별 맞춤 문장을 생성하고, AI 응답 길이의 가변성을 극복하는 3줄 강제 포맷터를 개발한다.

---

## 2. 작업 목록 (Tasks)

### Task 2.1: LLM 연동 클라이언트 (`lib/ai/client.ts`)
- [x] Google Gemini API REST 엔드포인트 연동 및 타임아웃(8초) 제어
- [x] 환경 변수(`GEMINI_API_KEY`) 로드 및 API Key 미제공/오류 시 스마트 AI Fallback 엔진 구비
- [x] 사용자 신체 정보(키, 몸무게)와 현재 심정을 완벽히 반영하는 어드바이스 생성 파이프라인

### Task 2.2: 톤별 프롬프트 엔지니어링 (`lib/ai/prompts.ts`)
- [x] 톤별 페르소나 및 시스템 지침 정의:
  - **쓴소리 (spicy):** 나태함을 깨우는 팩트 폭격 + 강렬한 이모티콘 (🔥, ⚡, 😤)
  - **현실직시 (realistic):** 객관적인 신체/상태 분석 + 실천 가능한 이모티콘 (🏋️‍♂️, ⏱️, 📊)
  - **따뜻한 공감 (warm):** 지친 마음 다독임 + 포근한 이모티콘 (🫂, 🌿, ✨)
- [x] 공통 시스템 지침: 이모티콘/특수문자 필수 포함, `\n` 기준 정확히 3줄 출력, 사용자 신체/심정 반영

### Task 2.3: 3줄 보장 포맷터 (`lib/ai/formatter.ts`)
- [x] 불필요한 번호, 따옴표, 마크다운 기호 제거 (`cleanedText`)
- [x] 1~2줄, 4줄 이상 등 불규칙한 길이의 응답에 대한 스마트 분할/병합 알고리즘 구현 (PRD 예외규칙 #3)
- [x] 이모티콘/표정 문자 누락 시 톤별 기본 이모티콘 자동 부착

### Task 2.4: API Route Handler 구현 (`app/api/advice/route.ts`)
- [x] POST 핸들러 구현: 입력값 파싱 -> 유효성 검사(400 반환) -> Sanitization -> AI 호출 -> 3줄 포맷팅 -> 200 반환
- [x] API Failure 및 예외 발생 시 표준 JSON 에러 반환 및 클라이언트 다운 방지
