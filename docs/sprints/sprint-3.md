# Sprint 3: 상태 관리, 애니메이션 및 5대 예외 처리 UI

> **스프린트 상태:** 📝 준비 중 (Planned)  
> **진행 기간:** Sprint Day 6 ~ Day 7  
> **관련 PRD 섹션:** 3.1(로딩/하단 결과 레이아웃), 4.3(상태 관리 및 내비게이션), 5.2(AI API Failure), 5.5(Debouncing Exception)

---

## 1. 스프린트 목표
* 뷰 상태머신(`form` | `loading` | `result` | `error`)을 단일 훅으로 관리하고, 중복 제출을 방어한다.
* 운동하는 캐릭터 CSS 애니메이션과 5~10초 응답 대기 UX를 완성하고, 재시도/재생성/초기화 플로우를 연결한다.

---

## 2. 작업 목록 (Tasks)

### Task 3.1: 흐름 제어 커스텀 훅 (`hooks/useAdviceFlow.ts`)
- [ ] 뷰 상태(`view`), 로딩 인덱스(`loadingIndex`), 조언 결과(`adviceLines`), 에러 상태 관리
- [ ] 제출 핸들러 `handleSubmit`: 검증 -> `view: loading` 전환 -> 5~10초 사이 AI 응답 대기 -> `view: result`
- [ ] 연속 클릭 방지: `isSubmitting` 플래그 및 Pointer-events 제어 (PRD 예외규칙 #5)
- [ ] 초기화 핸들러 `handleReset`: 폼 리셋 후 스크롤 상단 이동 및 첫 인풋 포커스
- [ ] 재생성 핸들러 `handleRegenerate`: 동일 입력값으로 AI 재호출

### Task 3.2: 로딩 애니메이션 컴포넌트 (`components/loading/LoadingCard.tsx`)
- [ ] 조금씩 움직이며 운동하는 캐릭터 CSS 애니메이션 (모션 라인, 팔다리 관절 애니메이션)
- [ ] 롤링 안내 텍스트 인터벌 전환 (`마음의 준비운동을 하는 중...` -> `당신에게 딱 맞는 말을 고르는 중...` -> `AI가 응원을 꽉 채우는 중...`)
- [ ] 로딩 도중 폼으로 돌아가는 `돌아가기` 내비게이션 버튼

### Task 3.3: 결과 화면 카드 컴포넌트 (`components/result/ResultCard.tsx`)
- [ ] 선택 톤 컬러 테마(Coral, Blue, Mint)가 적용된 3줄 조언 카드
- [ ] 컨트롤 버튼 그룹:
  - `원하는 느낌 나올 때까지 다시 생성` (재요청)
  - `다시 하기` (초기화 후 폼 이동)

### Task 3.4: 에러 Fallback 카드 컴포넌트 (`components/error/ErrorCard.tsx`)
- [ ] `"조언을 불러오지 못했어요 😢"` 및 경고 아이콘 노출 (PRD 예외규칙 #2)
- [ ] `다시 시도하기` 버튼 (동일 조건 재요청 트리거)

## 3. 완료 조건 (Definition of Done)
- [ ] `조언 받기` 버튼 클릭 후 5~10초 동안 운동하는 캐릭터 애니메이션이 정상 재생되는가?
- [ ] 로딩 상태 동안 추가 클릭이 발생하지 않도록 비활성화 및 디바운싱 처리되는가?
- [ ] API 호출 실패 시 에러 카드가 뜨고, `다시 시도하기`를 누르면 즉시 재요청되는가?
- [ ] `다시 하기` 클릭 시 모든 입력값이 리셋되고 폼의 첫 번째 인풋으로 스크롤/포커스 이동되는가?
